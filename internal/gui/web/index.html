How mods are checked

The September 2026 worm spread because the Workshop pushed code to every subscriber within hours. Each check below closes part of that path. No scanner makes mods safe: install mods from authors you trust.

Worm cutoff

Steam Workshop copies changed on or after are refused: that is when the worm started inserting itself into existing mods.

Cooldown

New GameBanana uploads must be at least hours old, giving the community and GameBanana's scanner time to catch bad uploads.

Source checks

GameBanana's own antivirus result must be clean and the file checksum must match.

Code scanner

Blocks process launching, networking, Steam Workshop uploads, Steam friends/chat, Steam login tickets, file deletion, self-copying into other mods, hidden code and shipped .exe/.dll files.

Blocklist

Known-bad mods listed in the GitHub repository are refused. The list can only block, never allow.

Tamper check

Every installed file is fingerprinted. Verify files reports anything changed or added afterwards, which is how the worm infected mods.

Safe updates

An update that adds new risky code is held back. Bad update anyway? Rollback restores the previous version.

Overrides

Only HIGH findings and the cooldown can be overridden here, per install. CRITICAL findings and the worm cutoff need the command line.
